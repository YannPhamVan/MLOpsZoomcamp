# MLOps Zoomcamp

This repository contains my work for the [MLOps Zoomcamp](https://datatalks.club/blog/mlops-zoomcamp.html) organized by [DataTalks.Club](https://datatalks.club/).

## 1. Course overview

The **MLOps Zoomcamp** teaches how to take Machine Learning models from the experimentation phase to production.  
It covers the best practices, tools, and techniques for the full ML lifecycle: training, deployment, monitoring, and automation.

The course is completely free and open-source. It is taught by [Alexey Grigorev](https://www.linkedin.com/in/agrigorev/) and other experienced MLOps practitioners.

## 2. Prerequisites

- Python programming skills
- Familiarity with Machine Learning concepts
- Basic knowledge of the command line and Git

---

## 3. Technologies and tools covered

The course introduces a variety of tools and technologies for MLOps, including:

- **Docker**
- **MLflow**
- **Prefect**
- **Evidently**
- **Prometheus**
- **Grafana**
- **Flask**
- **AWS / Google Cloud Platform**
- **CI/CD tools (GitHub Actions, etc.)**
- **Testing frameworks**
